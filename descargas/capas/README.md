# Capas KML

Aloje aquí las capas KML preparadas para distribución. Luego registre cada archivo en `herramientas.descargas.archivos` de `config/config.js`, por ejemplo `descargas/capas/capa.kml`.

No es necesario mover los GeoJSON del visor: permanecen en `data/`. El KML es un archivo independiente; revise sus geometrías y atributos antes de publicarlo.

Todo archivo publicado en esta carpeta puede ser accesible mediante su dirección directa, aunque su entrada esté deshabilitada en el panel. No aloje información reservada.
