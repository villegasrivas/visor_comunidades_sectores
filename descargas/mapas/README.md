# Mapas PDF

Aloje aquí los mapas PDF preparados previamente. Luego registre cada archivo en `herramientas.descargas.archivos` de `config/config.js`, por ejemplo `descargas/mapas/mapa-general.pdf`.

Copiar un archivo a esta carpeta no lo agrega automáticamente al panel. Use nombres claros, preferentemente sin espacios, y complete la fecha y descripción del documento.

Todo archivo publicado en esta carpeta puede ser accesible mediante su dirección directa, aunque su entrada esté deshabilitada en el panel. No aloje información reservada.
